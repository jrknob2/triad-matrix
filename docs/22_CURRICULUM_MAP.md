# 22 - Drumcabulary Curriculum Roadmap

## Purpose

This document defines the long-term educational roadmap for Drumcabulary.

It answers one question:

> **What should students learn, and in what order?**

It intentionally does **not** define:

- YAML structure
- notation syntax
- rendering
- Flutter screens
- implementation details

Those concerns are covered elsewhere.

This document exists solely to organize the educational journey.

---

# Philosophy

Students should never wonder:

> "What should I learn next?"

The curriculum should guide students through progressively more difficult musical concepts.

Each lesson should prepare the student for future lessons.

Difficulty should increase gradually while constantly reinforcing previously learned skills.

---

# Curriculum Structure

The curriculum is divided into three experience levels.

```
Beginner

↓

Intermediate

↓

Advanced
```

Within each level, learning is organized by skill.

A skill contains one or more lessons.

Each lesson contains progressively structured exercises.

```
Level

    Skill

        Lesson

            Exercise
```

---

# Beginner

The Beginner curriculum focuses on building confidence, coordination, and musical time.

Students should develop:

- internal pulse
- basic coordination
- simple grooves
- simple fills
- musical confidence

- Eighth Notes
- Counting
- Internal Pulse

Example lessons:

- Playing Eighth Notes
- Counting Out Loud

# Lesson Dependencies

Lessons should build naturally upon previous lessons.

Example:

```
Quarter Notes

↓

Eighth Notes

↓

Hi-Hat

↓

Backbeat

↓

Money Beat

↓

Crash Resolution

↓

Basic Fill

↓

Money Beat + Fill
```

Students should not encounter concepts before the prerequisite skills have been introduced.

---

# Reinforcement

Previously learned skills should continue appearing throughout the curriculum.

For example:

The Money Beat should continue to appear long after the original Money Beat lesson.

Students improve through repetition and application, not through one-time exposure.

---

# Curriculum Growth

This roadmap is intentionally incomplete.

As Drumcabulary grows, new lessons should fit naturally into the existing progression rather than being inserted randomly.

When adding new content, authors should ask:

1. Which level does this belong in?
2. Which skill does it develop?
3. What prerequisite knowledge is required?
4. What future lessons does it prepare the student for?

If these questions cannot be answered clearly, the lesson may not yet have a proper place in the curriculum.

---

# Long-Term Vision

The goal of Drumcabulary is not to teach isolated exercises.

The goal is to develop complete musicians.

Students should gradually build:

- confidence
- coordination
- timing
- technique
- vocabulary
- creativity
- musicality

Every lesson should move the student one step closer to playing music naturally and confidently.
