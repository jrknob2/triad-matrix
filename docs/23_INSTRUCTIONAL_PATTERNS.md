# 23 - Instructional Patterns

## Purpose

This document defines the instructional patterns used throughout Drumcabulary.

Instructional patterns describe **how a lesson is taught**, not **what is being taught**.

For example:

- A rudiment
- A groove
- A fill
- An independence exercise

are musical concepts.

The instructional pattern defines the sequence of learning used to teach those concepts.

Using consistent instructional patterns creates a familiar learning experience and makes lesson authoring more consistent.

---

# Philosophy

Every lesson should answer one question:

> **What is the simplest sequence of steps that leads the student from understanding to musical application?**

The instructional pattern should match the type of material being taught.

Not every lesson uses every stage.

Authors should include only the stages that improve learning.

---

# Build Pattern

Purpose:

Introduce one limb or one concept at a time.

Best used for:

- beginner grooves
- coordination
- independence
- basic timing

Typical progression:

```
Step 1

One limb

↓

Step 2

Add one new limb

↓

Step 3

Add another limb

↓

Step 4

Complete pattern

↓

Step 5

Loop and reinforce

↓

Step 6

Simple musical application
```

Example:

Money Beat

```
HH

↓

HH + Snare

↓

HH + Snare + Kick

↓

Money Beat

↓

Four-Bar Loop

↓

Crash Resolution
```

---

# Vocabulary Pattern

Purpose:

Teach a family of related ideas.

Best used for:

- triplets
- linear ideas
- sixteenth vocabulary
- kick vocabulary

Typical progression:

```
Pattern A

↓

Pattern B

↓

Pattern C

↓

Alternate

↓

Combine

↓

Apply
```

Students first learn each vocabulary item independently before combining them.

---

# Rudiment Pattern

Purpose:

Transform a rudiment into usable musical vocabulary.

Typical progression:

```
Learn

↓

Control

↓

Dynamics

↓

Movement

↓

Application

↓

Expansion

↓

Creativity
```

Example:

Six Stroke Roll

Learn sticking

↓

Add accents

↓

Ghost notes

↓

Move around kit

↓

Groove application

↓

Creative combinations

---

# Fill Pattern

Purpose:

Teach musical fills.

Typical progression:

```
Vocabulary

↓

Timing

↓

Movement

↓

Resolution

↓

Application
```

Students should always understand where the fill begins and where it resolves.

Musical timing is more important than speed.

---

# Groove Pattern

Purpose:

Teach complete grooves.

Typical progression:

```
Foundation

↓

Coordination

↓

Consistency

↓

Variation

↓

Application
```

Students should leave the lesson able to use the groove in music rather than simply repeat it.

---

# Independence Pattern

Purpose:

Develop limb independence.

Typical progression:

```
Ostinato

↓

Add Limb

↓

Control

↓

Variation

↓

Application
```

The ostinato should become automatic before introducing additional coordination.

---

# Reading Pattern

Purpose:

Develop music reading.

Typical progression:

```
Recognition

↓

Execution

↓

Fluency

↓

Application
```

Students should first recognize rhythms before attempting to play them.

---

# Dynamics Pattern

Purpose:

Develop touch and control.

Typical progression:

```
Even Notes

↓

Accents

↓

Ghost Notes

↓

Balance

↓

Musical Application
```

Dynamic control should always be developed before speed.

---

# Speed Pattern

Purpose:

Increase tempo without sacrificing technique.

Typical progression:

```
Slow Accuracy

↓

Consistency

↓

Controlled Tempo Increase

↓

Performance Tempo

↓

Musical Application
```

Speed should never be introduced before accuracy.

---

# Creativity Pattern

Purpose:

Develop musical thinking.

Typical progression:

```
Review

↓

Variation

↓

Combination

↓

Improvisation

↓

Reflection
```

Students should gradually move from repeating ideas to creating their own.

---

# Combining Instructional Patterns

Some lessons naturally combine multiple instructional patterns.

Example:

Money Beat + Triplet Fill

Instructional Flow

```
Build Pattern

↓

Vocabulary Pattern

↓

Fill Pattern

↓

Groove Pattern
```

The student first learns the groove.

Then the vocabulary.

Then the fill.

Finally both are combined musically.

---

# Choosing An Instructional Pattern

When authoring a new lesson, first determine:

1. What musical idea is being taught?
2. Which instructional pattern best fits that idea?

Examples:

| Musical Concept | Instructional Pattern |
|-----------------|----------------------|
| Money Beat | Build Pattern |
| Six Stroke Roll | Rudiment Pattern |
| Triplet Vocabulary | Vocabulary Pattern |
| Basic Fill | Fill Pattern |
| Shuffle Groove | Groove Pattern |
| Four-Way Independence | Independence Pattern |
| Reading Syncopation | Reading Pattern |
| Accent Control | Dynamics Pattern |
| Speed Development | Speed Pattern |

---

# Authoring Principle

The instructional pattern should always serve the student.

If a stage does not improve learning, omit it.

Lessons should remain concise, focused, and progressive.

The goal is not to complete every stage.

The goal is to teach the musical idea as clearly and efficiently as possible.

---

# Long-Term Vision

Students should eventually recognize Drumcabulary's teaching style regardless of the lesson.

Every lesson should feel familiar.

Every lesson should build confidence.

Every lesson should move naturally from understanding to musical application.

Consistency in teaching creates confidence in learning.
